# OpenRazer native route

> Generated by `./hfx generate` from `architecture/repository-atlas.json`. Do not edit manually.

Extends pinned OpenRazer with trusted feature-only HyperFlux routes while preserving ordinary USB devices and the official daemon API.

## Start Here

- [Integration Boundary](../../docs/architecture/integrations.md)
- [Application Integrations](../../docs/generated/integrations.md)

## Limitations

- Native-route physical method parity remains pending for stock OpenRazer and Polychromatic clients

## Boundaries

**Owns**
- Feature-only UHID route contract
- Pinned OpenRazer source transform
- Serial-proven direct-route precedence metadata

**Does not own**
- OpenRazer device semantics
- Official daemon identity
- Direct USB transport
