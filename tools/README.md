# Repository tooling

> Generated by `./hfx generate` from `architecture/repository-atlas.json`. Do not edit manually.

The `./hfx` developer command: it loads the repository's data files, generates documentation and code from them, and runs the checks.

## Limitations

- Tooling projects canonical truth; it is not an independent product authority

## Boundaries

**Owns**

- Developer command surface
- Canonical data loaders
- Deterministic generation

**Does not own**

- Duplicate domain facts
- Implicit hardware writes
- Hidden network access
