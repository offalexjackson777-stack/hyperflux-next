# Pinned development toolchains

Pins the compiler, interpreter, upstream source and development container versions so every build and check is reproducible.

## Limitations

- Preparing upstream checkouts may require network access outside offline verification

## Boundaries

**Owns**

- Toolchain versions
- Development environment pins
- Capability discovery inputs

**Does not own**

- Runtime dependencies
- Automatic remote mutation
- Unpinned downloads
