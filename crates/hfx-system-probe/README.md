# System probe

> Generated by `./hfx generate` from `architecture/repository-atlas.json`. Do not edit manually.

Inspects the local system for the operator tools: which driver is loaded, whether Full is installed, and how to switch drivers safely while the receiver is disconnected.

**Does not own**

- Qualification policy

- Installed command parsing
