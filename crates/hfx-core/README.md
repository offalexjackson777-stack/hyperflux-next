# Core policy engine

> Generated by `./hfx generate` from `architecture/repository-atlas.json`. Do not edit manually.

Decides what may be sent to each device and when. It keeps requests from different apps from clashing, sends each one as a single complete exchange, restores the device after a failure, and reports errors with a reason.

## Start Here

- [Bridge Core Boundaries](../../docs/architecture/bridge-core.md)
- [Bridge Persistence](../../docs/architecture/persistence.md)

## Limitations

- The core never performs transport or filesystem I/O directly

## Boundaries

**Owns**

- Core state machines
- NativeControl and transaction policy
- Retained restoration intent

**Does not own**

- Socket framing
- Kernel I/O
- Application presentation
