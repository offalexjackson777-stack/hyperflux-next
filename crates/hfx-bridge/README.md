# Bridge runtime

> Generated by `./hfx generate` from `architecture/repository-atlas.json`. Do not edit manually.

Connects apps to the core: it accepts their requests over the current and the previous message protocol, remembers settings, sends updates to subscribers, and answers each request within set limits.
