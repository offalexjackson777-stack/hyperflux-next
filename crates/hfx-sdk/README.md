## Limitations

- The Rust SDK is local-process infrastructure, not a network API

## Boundaries

**Owns**

- Rust client API
- Native route and channel adaptation
- Typed SDK errors

**Does not own**

- Application presentation
- Device command semantics
- Receiver carrier frames
- Bridge policy
