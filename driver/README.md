# Kernel driver contract

> Generated by `./hfx generate` from `architecture/repository-atlas.json`. Do not edit manually.

Defines the interface between the kernel driver and the programs that use it. New versions only add to it, so existing programs keep working.

## Start Here

- [Kernel Boundary](../docs/architecture/kernel.md)
- [Kernel UAPI](../docs/generated/kernel-uapi.md)

## Limitations

- Live loading and physical validation are outside software verification

## Boundaries

**Owns**

- Kernel UAPI authority
- Driver source boundary
- Session-device contract

**Does not own**

- Retail presentation
- Effects
- Application ownership
