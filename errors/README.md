# Error catalog

> Generated by `./hfx generate` from `architecture/repository-atlas.json`. Do not edit manually.

Defines stable typed error identities, user-safe messages, remediation, and cross-language mappings.

## Start Here

- [Error Catalog](../docs/generated/error-catalog.md)
- [Troubleshooting](../docs/user/troubleshooting.md)

## Limitations

- The catalog cannot replace structured subsystem diagnostics

## Boundaries

**Owns**

- Error identifiers
- User remediation text
- Error severity and domain

**Does not own**

- Ad hoc application-only errors
- Private diagnostics
- Transport policy

## Key Files

- [`errors/catalog.json`](catalog.json)

## Verify

Run `error-contracts` after changing this area, and run `./hfx generate` to refresh its 3 generated file(s).

Maintainers can find the areas this one depends on and the areas that use it in the [Repository Atlas](../docs/generated/repository-atlas.md).
