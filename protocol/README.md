# Versioned bridge protocol

> Generated by `./hfx generate` from `architecture/repository-atlas.json`. Do not edit manually.

Defines the messages apps and tools exchange with the HyperFlux background service, and how older and newer versions of those messages stay compatible.

## Start Here

- [Bridge Protocol](../docs/generated/bridge-protocol.md)
- [SDK Boundary](../docs/architecture/sdk.md)

## Limitations

- Wire compatibility alone does not admit a hardware route
- Versions 1 to 4 and 6 were retired in 2.2; negotiate version 5 or 7, and version 7 carries everything version 6 added

## Boundaries

**Owns**

- Protocol registry
- Versioned wire schemas
- Compatibility window

**Does not own**

- Application widgets
- Kernel HID payloads
- Unbounded messages
