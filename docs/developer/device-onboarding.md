# Device Onboarding

New device support starts from upstream authority and capability evidence, not
from a local serial, receiver path, or vendor-wide rule.

## Process

Import exact upstream identity and command evidence, classify operational and
research-only capabilities, regenerate route catalogs, and run negative as well
as positive contracts. Physical qualification is a separate final assurance
step.
