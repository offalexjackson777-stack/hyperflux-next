# SDK And Connectors

The stable connector boundary exposes versioned route discovery, lifecycle
watching, and bounded transaction APIs without leaking receiver transport
details into applications.

## Public Contract

Connectors consume qualified routes and carry standard application-owned
reports. They do not decide eligibility, bypass generations, or gain direct USB
authority.
