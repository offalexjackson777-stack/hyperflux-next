# Verification

The verification graph maps source ownership to bounded evidence. A passing
test proves only its declared software or hardware requirement; it cannot grant
publication or live-device authority.

## Development Lanes

Use focused tests while editing, Fast verification for ordinary checkpoints,
and the complete software graph at phase exits. Hardware nodes require explicit
authorization and preserved evidence.
