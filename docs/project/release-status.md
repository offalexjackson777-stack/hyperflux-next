## Release State

HyperFlux Next 2.0.0-1 Core and Full packages for Arch Linux x86_64 are
published through GitHub Release `v2.0.0`. The release remains bound to the
verified source, package manifests, checksums, SBOM, and accepted physical
evidence.

## Availability

The GitHub Release is the current package channel. There is no pacman repository
or published signing key; users verify `SHA256SUMS` and install both local files
with `pacman -U` as documented in the [installation guide](../user/installation.md).
