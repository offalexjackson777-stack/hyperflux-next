# Roadmap

HyperFlux Next 2.0 is reconstructing the accepted private release 8 behavior
into a lean Core package and an integration-complete Full package.

## Current Sequence

1. Complete source reconstruction, documentation, and offline verification.
2. Freeze and qualify the Arch 2.0 candidate.
3. Obtain explicit authorization for final physical parity evidence.
4. Prepare a clean public-history cutover without deleting prior history.
5. Add other native distribution backends independently after the Arch boundary.

## Not In This Release

Restoration remains disabled. Ripple and the OpenRGB Quartz label remain
accepted limitations. Publication, remote changes, and package-channel work are
locked to later explicit authorization.
