## Terms

These terms mean the same thing on every generated page.

| Term | Meaning |
| --- | --- |
| Receiver | The HyperFlux V2 USB receiver, exact `1532:00CF`. Every HyperFlux command to a child goes through it. |
| Child | A wireless mouse or keyboard reached through the receiver by its wireless product ID. |
| Mat | The HyperFlux V2 charging surface, device kind `mat`. HyperFlux has no native route to the mat. |
| Hard Edition | The mat surface variant with the profile `surface.razer.hyperflux-v2-hard-edition`. |
| Cloth Edition | The other mat surface variant. It has no profile, no physical evidence, and no invented USB identity. |
| Route | One qualified path from a stock application to one child through the receiver. |
| Compatibility snapshot | The official Razer compatibility list `catalog.razer.hyperflux-v2.2026-07-21` that bounds which children HyperFlux considers. |
| Support tier | One of the three public tiers defined in [Supported Hardware](supported-hardware.md). |
