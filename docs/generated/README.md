# Generated Reference

> Generated by `./hfx generate`. Do not edit manually.

This page lists every reference page that is built from the project's data files, for anyone looking up exact facts such as supported devices, error codes, or package contents.

To change a page, change the file it is generated from and run `./hfx generate`;
never edit a page directly. For guides, start at the
[documentation hub](../README.md).

## Terms

These terms mean the same thing on every generated page.

| Term | Meaning |
| --- | --- |
| Receiver | The HyperFlux V2 USB receiver, exact `1532:00CF`. Every HyperFlux command to a wireless device goes through it. |
| Child | A wireless mouse or keyboard that HyperFlux reaches through the receiver, identified by its wireless product ID. |
| Mat | The HyperFlux V2 charging mat, device kind `mat`. HyperFlux does not control the mat itself. |
| Hard Edition | The hard-surface version of the mat, with the profile `surface.razer.hyperflux-v2-hard-edition`. |
| Cloth Edition | The cloth-surface version of the mat. It has no profile, has not been tested on real hardware, and HyperFlux does not guess its USB ID. |
| Route | One tested path from one of your apps to one device through the receiver. |
| Compatibility snapshot | The official Razer compatibility list `catalog.razer.hyperflux-v2.2026-07-21`. HyperFlux only considers devices on this list. |
| Support tier | Tested on real hardware, expected to work, or not supported yet, as defined in [Supported Hardware](supported-hardware.md). |
