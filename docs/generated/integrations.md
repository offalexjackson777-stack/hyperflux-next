## Rules Every Integration Follows

- Integrations never open HID, USB, sysfs, or the receiver directly.
- OpenRGB owns its model layouts, LED labels, profiles, and effect engine.
- HyperFlux never suppresses unrelated OpenRGB, OpenRazer, or Polychromatic devices.
- Unmodified OpenRazer keeps its own service name and public client API.
- Unmodified Polychromatic uses only the ordinary OpenRazer API.
- Each app's source version is reviewed and pinned; builds never download anything that could change.
