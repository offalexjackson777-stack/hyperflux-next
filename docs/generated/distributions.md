## Ownership Boundary

- **Core (`hyperflux-next-linux`):** HyperFlux receiver driver, bridge, SDK, CLI, and base services.
- **Full (`hyperflux-next-full`):** Core plus the OpenRazer compatibility transport and OpenRGB integration for optional stock applications.
- Stock applications are optional suggestions rather than package payloads.
- Stock OpenRazer daemon/client, Polychromatic, and OpenRGB remain distribution-owned applications.

## Lifecycle Contract

- Package hooks create system users/directories and reload systemd and udev registration only.
- Installation does not start, stop, restart, enable, disable, or probe services or hardware.
- Activation is a separate reviewed step: `systemctl enable --now hyperflux-next-bridge.service hyperflux-next-client@<uid>.socket`.
- Bridge restoration ships disabled in this package release.

## Architecture

`aarch64-unknown-linux-gnu` maps to `aarch64`, `x86_64-unknown-linux-gnu` maps to `x86_64`.
