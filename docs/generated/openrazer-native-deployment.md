| Bridge socket | `/run/hyperflux-next/bridge.sock` |
| Exclusive kernel interface | `/dev/uhid` |

The static relay service is pulled in by the bridge service. It runs as root only because `/dev/uhid` remains unavailable to ordinary users, drops every Linux capability, joins only the `hyperflux` bridge-socket group, and can access only the bridge socket and UHID device. A separate stateless oneshot validates read-only transformed-driver metadata before this sealed relay namespace is entered. The oneshot has a transient identity, exposes no sockets, devices, or capabilities, hides the bridge runtime, and blocks module syscalls. The relay itself tolerates only a bounded startup interval in which the bridge socket is still absent; protocol or configuration failures remain immediate and the service never schedules an automatic restart.
