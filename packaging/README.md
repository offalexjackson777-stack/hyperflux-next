# Packaging and installation

> Generated by `./hfx generate` from `architecture/repository-atlas.json`. Do not edit manually.

Builds the Arch packages the same way every time, and the signed Pacman repository that serves them.

## Start Here

- [Package Installation](../docs/generated/installation.md)

## Limitations

- Private signing material remains outside the publishable repository and release assets

## Boundaries

**Owns**

- Install manifest
- Distribution projections
- Reproducible package inventory
- Published package-signing public key

**Does not own**

- Runtime naming duplicates
- Hidden post-install writes
- Release decisions
